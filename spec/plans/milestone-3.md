# תוכנית — M3: סבבים, ניקוד ומצבי סיום

**מקורות:** `MILESTONES.md` (M3), `PRD.md` (FR-03, FR-04, Edge Cases, "התחלה מחדש במהלך סבב"), `ARCHITECTURE.md` (2.3, 2.4), `DESIGN.md` (1.2), `wireframes.png`, `mockups.png`.

## נקודת המוצא (מה כבר קיים מ-M2)

- `gameReducer` כבר מטפל בפעולת `answer`: נקודה אחת לתשובה נכונה, `mistakesOnCurrent` בטעות ראשונה, `lost` בטעות שנייה, `won` כש-`score === 55`, ו-`bestScore = max(bestScore, score)` בכל תשובה נכונה.
- `PracticeScreen` כבר מציג ניקוד בפורמט "n מתוך 55", ומצב סיום **בסיסי** (כותרת בלבד).
- כפתור "התחל מחדש" קיים אך מושבת.
- `bestScore` נשמר בזיכרון בלבד; אינו מוצג עדיין (תצוגה במסך אודות ושמירה קבועה — M4).

## מה נבנה

### 1. מצב המשחק — `src/game/gameState.ts`
- פעולה חדשה: `{ type: 'newRound'; round: Round }`.
  - הסבב החדש נוצר **מחוץ** ל-Reducer (`createRound()`) ומועבר בפעולה, כדי שה-Reducer יישאר טהור (בלי אקראיות בתוכו) והבדיקות יהיו צפויות.
  - התוצאה: `{ bestScore: state.bestScore, round: action.round }` — ניקוד, מיקום, טעויות ורשימת התרגילים שנפתרו מתאפסים; השיא נשמר.
  - פעולה אחת משמשת את שלושת הכפתורים: "כן, להתחיל מחדש", "נסו שוב!", "התחל סבב חדש".
- `answer` במצב `lost`/`won` ממשיך להחזיר את אותו מצב (כבר קיים — נוודא בבדיקה). כך אין ניסיון לבחור "תרגיל 56".
- אין שינוי ב-`GameContext.tsx`.

### 2. ניווט — `src/App.tsx`
- `PracticeScreen` מקבל `onNavigate` (כמו `HomeScreen`), עבור "חזרה לבית".
- "חזרה לבית" מחליף מסך בלבד; מצב `lost`/`won` נשאר, וחזרה ל"תרגול" מציגה שוב את מצב הסיום.

### 3. מצב סיום — רכיב חדש `src/components/RoundResult.tsx` + `RoundResult.module.css`
מוצג בתוך מסך התרגול במקום התרגיל, השדה וכפתור "התחל מחדש" (DESIGN 1.2). סרגל הניווט לא משתנה. תג הניקוד העליון לא מוצג במצבי סיום (כמו ב-Wireframes — הניקוד מופיע בכרטיס).

| | ניצחון (`won`) | פסילה (`lost`) |
|---|---|---|
| סמל | גביע (Accent `#F59E0B`) | עיגול אדום עם × (Error) |
| כותרת (H1) | **"כל הכבוד!"** | **"הסבב הסתיים"** |
| שורת הסבר | "פתרת את כל 55 התרגילים בהצלחה!" | "לא הצלחת לפתור את התרגיל בשתי ההזדמנויות." |
| כרטיס ניקוד | "הניקוד שלך" / **55** / "מתוך 55" | "הניקוד שלך" / **n** (Error Text) / "מתוך 55" |
| כפתור ראשי | **"התחל סבב חדש"** | **"נסו שוב!"** |
| כפתור משני | **"חזרה לבית"** | **"חזרה לבית"** |

- Props: `status`, `score`, `onNewRound`, `onHome`.
- הכותרת מקבלת Focus בהופעת המצב, כדי שקוראי מסך יכריזו עליו.
- עיצוב בסיסי ונקי לפי ה-Style Guide (צבעים, פינות, כפתורים קיימים `btn-primary`/`btn-secondary`); ליטוש סופי וקישוטים — M5.

### 4. אייקונים — `src/components/icons.tsx`
- `TrophyIcon` ו-`LostIcon` כ-SVG פשוטים מקומיים (DESIGN: "אייקוני הממשק ... ייבנו כ-SVG פשוטים").

### 5. חלונית אישור — רכיב חדש `src/components/ConfirmDialog.tsx` + `ConfirmDialog.module.css`
- חלונית בתוך האפליקציה (לא `window.confirm`): כרטיס ממורכז על רקע מוחשך.
- טקסט: **"להתחיל סבב חדש? הניקוד בסבב הנוכחי יימחק, השיא האישי יישמר."**
- כפתורים: ראשי **"כן, להתחיל מחדש"**, משני **"ביטול"**.
- נגישות: `role="dialog"`, `aria-modal="true"`, `aria-labelledby`; Focus עובר לכפתור "ביטול" (הבחירה הבטוחה) בפתיחה; מקש Escape = ביטול; לחיצה על הרקע המוחשך = ביטול.
- Props: `message`, `confirmLabel`, `cancelLabel`, `onConfirm`, `onCancel`.

### 6. מסך התרגול — `src/screens/PracticeScreen.tsx`
- כפתור **"התחל מחדש"** הופך לפעיל ופותח את החלונית (`confirmOpen` — UI state מקומי, לא חלק מהמשחק).
  - מושבת בזמן הודעת ההצלחה (1.5 שניות), כדי למנוע התנגשות עם המעבר האוטומטי.
- **ביטול:** סגירת החלונית בלבד — התרגיל, הניסיון שנותר, הניקוד, הטקסט שהוקלד והודעת המשוב נשארים כפי שהיו.
- **אישור / "נסו שוב!" / "התחל סבב חדש":** פונקציה אחת `startNewRound()`:
  `dispatch({ type: 'newRound', round: createRound() })`, ניקוי השדה, ההודעה וה-`solvedPair`, סגירת החלונית, והחזרת Focus לשדה התשובה.
- מצב סיום: מוחלף ב-`<RoundResult>` (במקום הכותרת הבסיסית מ-M2). ממשיך לחכות לסוף הודעת ההצלחה לפני הצגת הניצחון.
- הטקסטים החדשים נוספים לאובייקט `MESSAGES` הקיים.

### 7. סימון התקדמות

## בדיקות אוטומטיות

**`src/game/gameState.test.ts` (Reducer):**
- תשובה נכונה מוסיפה בדיוק נקודה אחת; טעות ראשונה לא משנה את הניקוד ולא את `index`.
- `newRound` מאפס `score`, `index`, `mistakesOnCurrent`, ו-`status='playing'`, ומשתמש ב-`order` החדש; `bestScore` נשמר.
- שיא: עולה כשהניקוד עובר אותו; לא יורד אחרי סבב חדש או סבב חלש יותר.
- 55 תשובות נכונות ברצף ← `won`, ניקוד 55, שיא 55; `answer` נוסף אחרי ניצחון/פסילה אינו משנה דבר.

**`src/screens/PracticeScreen.test.tsx` (ממשק):**
- שתי טעויות ← "הסבב הסתיים", ניקוד הסבב, "נסו שוב!" ו"חזרה לבית"; שדה התשובה ו"התחל מחדש" לא מוצגים; אין סבב חדש אוטומטי (גם אחרי המתנה).
- "נסו שוב!" ← תרגיל חדש, "0 מתוך 55", שדה ריק.
- ניצחון: מצב התחלתי עם `index=54, score=54` ← תשובה נכונה ← אחרי 1.5 שניות "כל הכבוד!", "55" ו"התחל סבב חדש"; לחיצה מתחילה סבב בניקוד 0.
- "התחל מחדש" ← חלונית עם הטקסט והכפתורים; "ביטול" (וגם Escape) ← אותו תרגיל ואותו ניקוד; ואחרי טעות ראשונה + ביטול, טעות נוספת עדיין מסיימת את הסבב (יתרת הניסיונות נשמרה).
- "כן, להתחיל מחדש" ← ניקוד 0, תרגיל חדש, השיא (`bestScore` במצב) נשמר.
- "התחל מחדש" מושבת בזמן הודעת ההצלחה.
- "חזרה לבית" קורא ל-`onNavigate('home')`.

**`src/App.test.tsx`:**
- אחרי פסילה: מעבר לבית וחזרה לתרגול ← מצב הסיום עדיין מוצג; סרגל הניווט נשאר עם שלושת היעדים בלבד, ו"תרגול" מסומן כפעיל.

עזר לבדיקות: פונקציה ב-`src/test/helpers.ts` שבונה `GameState` במיקום נתון בסבב (למשל `index=54`), כדי לבדוק ניצחון בלי 55 הקלדות בממשק.
